# Standard-cell libraries

The TSMC 0.13 µm (CL013G) standard-cell libraries are licensed technology files
and are not distributed in this repository.

The flows expect the following files and directories:

- `.db` and `.lib` timing libraries
- `libs/` timing libraries
- `lef/` technology and macro LEF files
- `captables/tsmc13fsg.capTbl`
- `tsmc13_m.v` standard-cell Verilog models
